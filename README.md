# Mohamed Elmwafy — Portfolio

A responsive static portfolio website for GitHub Pages.

## Files
- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — mobile navigation
- `assets/profile.jpg` — profile image

## GitHub Pages
Create a repository and upload the files to the repository root. GitHub Pages uses `index.html` as the entry file.

For a personal site, the repository can be named:
`mwafyy.github.io`

Then go to:
Settings → Pages → Build and deployment → Source → Deploy from a branch → `main` → `/ (root)` → Save.

Your site should be available at:
`https://mwafyy.github.io/`

The site is intentionally built with plain HTML/CSS/JS, so it can be hosted directly on GitHub Pages.
